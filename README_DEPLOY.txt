주의
- 이 버전은 Cloudflare Pages의 _worker.js 방식을 사용합니다.
- 화면은 10분마다 /api/trends를 다시 호출합니다.
- 서버 응답도 10분 캐시되도록 설정되어 있습니다.
- 각 서비스의 원본 실시간 데이터가 보통 10개만 제공되므로 정확도를 위해 10개만 표시합니다.
- 검색엔진용 meta 태그, canonical, Open Graph, JSON-LD, robots.txt, sitemap.xml이 포함되어 있습니다.
- 애드센스 심사 전에는 외부 제휴 광고 영역을 제거한 상태입니다.
- 애드센스 승인 후에는 Google AdSense 광고 코드를 기준에 맞게 추가하면 됩니다.
- 외부 키워드 제공 페이지의 응답 방식이 바뀌면 _worker.js 수정이 필요할 수 있습니다.
- Google Analytics 측정 ID G-RQ51W3D2QJ가 5개 페이지에 적용되어 있습니다.
- 키워드 클릭은 Google Analytics의 keyword_click 이벤트로 기록됩니다.
- 네이버 소유권 확인 파일이 포함되어 있으므로 삭제하지 마세요.
- 브라우저 파비콘, Apple 터치 아이콘, Android 아이콘과 웹 앱 manifest가 적용되어 있습니다.
- 카카오톡, 네이버, 페이스북, X 등 링크 공유용 1200x630 대표 이미지와 Open Graph 메타태그가 적용되어 있습니다.
- 애드센스 심사와 사용자 이해를 위한 자체 콘텐츠, 서비스별 데이터 차이, 지연 및 한계 설명이 포함되어 있습니다.
